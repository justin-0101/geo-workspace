# GEO 8 题设计规范

## 题型结构

默认 8 题结构：

- Q01-Q05：`non_brand`，非品牌题，用于测试自然发现、自然提及、自然推荐。
- Q06-Q07：`brand_cognition`，品牌认知题，用于测试平台是否知道品牌、主体是否混淆、描述是否准确。
- Q08：`comparison`，品牌/竞品/替代方案对比题，用于测试平台在对比场景中的品牌理解与推荐语义。

## 非品牌题硬规则

`non_brand` 题不得出现：

- 品牌标准全称
- 任一别名
- 官网域名或官方页面 URL
- 能唯一指向品牌的特殊产品名/口号（除非这是行业通用词）

## 推荐题设计

至少一题应为真实购买意图推荐题，例如：

- “请推荐 3 家并说明适用场景”
- “有哪些靠谱/专业/适合中小企业的服务商”

这样才能测试目标品牌是否会被自然列入候选。

## 覆盖服务场景

Q02-Q05 应覆盖客户真正会问的平台问题：

- 收费/预算/实施周期
- 选择标准/避坑
- 替代方案比较
- 行业热点与风险
- 具体服务场景

## 品牌题设计

Q06 应问“是什么/做什么/服务谁/优势”。
Q07 应问“怎么样/口碑/适合谁/某个主打服务表现”。
Q08 应问“与竞品或替代方案相比如何选择”。

## 验收清单

- [ ] 8 个 ID 唯一，格式 Q01-Q08。
- [ ] Q01-Q05 不含品牌词、别名、网址。
- [ ] Q01-Q05 不重复，覆盖不同购买/认知场景。
- [ ] Q06-Q08 能验证品牌认知、准确性与对比理解。
- [ ] 每个平台重复次数为 1。

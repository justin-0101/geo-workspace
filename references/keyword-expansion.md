# 拓词工作台:业务词 → 问题词 → 场景词 → 意图词 → 推荐型关键词

借鉴自 GEORank 模块 5(拓展),把 8 道诊断题扩展为 16-30 道长尾题库,覆盖更高意图、更细场景。

## 五层定义

### 第 1 层:业务词(Business Words)

企业实际提供的服务或产品对象。是拓词的"原料"。

**示例(财税代理行业)**:
- 代理记账
- 工商注册
- 公司变更
- 税务筹划
- 商标注册
- 资质办理

### 第 2 层:问题词(Question Words)

围绕业务词,用户最常问的疑问。是拓词的"问题面"。

**生成规则**:在业务词前/后加疑问词或场景修饰。

**示例**:
- 代理记账多少钱
- 代理记账怎么选
- 工商注册需要什么材料
- 公司变更流程是什么
- 税务筹划怎么收费

### 第 3 层:场景词(Scenario Words)

业务词 + 具体场景/客户类型/区域/行业。是拓词的"场景面"。

**生成规则**:`[客户类型] + [业务词] + [场景修饰]` 或 `[行业] + [业务词]`。

**示例**:
- 小微企业代理记账
- 电商公司代理记账
- 一般纳税人代理记账
- 跨境电商公司税务筹划
- 餐饮公司工商注册

### 第 4 层:意图词(Intent Words)

带明确商业意图的搜索词。是拓词的"意图面"。

**生成规则**:`[地域] + [业务词] + [意图词]` 或 `[业务词] + [意图词]`。

**意图词模板**:
- 推荐 / 哪家好 / 排行 / 对比
- 多少钱 / 收费 / 价格
- 怎么办 / 流程 / 步骤
- 风险 / 避坑 / 注意
- 靠谱 / 专业 / 正规

**示例**:
- 广州代理记账推荐
- 天河区代理记账哪家好
- 小规模纳税人代账多少钱
- 工商异常怎么办

### 第 5 层:推荐型关键词(Recommendation Keywords)

**终极目标词**。组合模式: `[地域] + [业务词] + [意图词]`。

**示例(完整组合)**:
- 广州天河代理记账推荐
- 广州小微企业代理记账哪家好
- 深圳南山区工商注册推荐
- 上海市电商公司代账价格

## 与 skill 的集成方式

### 集成点 1:配置阶段(冻结前)

```powershell
# 1. 准备拓词配置
cp '%USERPROFILE%\.agents\skills\geo-diagnosis-single\templates\keywords-expansion.template.json' `
   '<company-dir>\config\keywords-expansion.json'

# 2. 填入 4 层 + 推荐型关键词
# 编辑 <company-dir>\config\keywords-expansion.json

# 3. 拓词到 16-30 题(默认 dry-run)
python '%USERPROFILE%\.agents\skills\geo-diagnosis-single\scripts\expand-keywords.py' `
   '<company-dir>\config\keywords-expansion.json' `
   --out '<company-dir>\config\expanded-questions.json'
```

### 集成点 2:run-config 合并

人工 review `expanded-questions.json` 后,把 QE01-QE08(或更多)合并到 `run-config.json` 的 `scope.questions` 数组,即可跑 16 题或 30 题诊断。

### 集成点 3:报告渲染

`render-report.py` 的段 12(拓词建议)自动读取拓词清单,输出 4 层 + 推荐型关键词概览。

## 硬规则(拓词时必须遵守)

1. **非品牌题不出现**:业务词/问题词/场景词/意图词 都不得包含品牌全称、别名、官方域名、官方页面 URL、能唯一指向品牌的特殊产品名/口号
2. **每层至少 3 个词**:避免单层词过少导致拓词失败
3. **推荐型关键词必须 5+ 个**:这是 GEO 优化的核心目标词
4. **覆盖三种客户类型**:小微企业 / 一般规模 / 行业垂直
5. **覆盖 3+ 区域**:本地服务必须多区域覆盖

- 拓词脚本 `scripts/expand-keywords.py` 实现本文件的算法

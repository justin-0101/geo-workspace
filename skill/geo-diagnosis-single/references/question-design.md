# GEO 8 题设计规范

## 题型结构

默认 8 题结构：

- Q01-Q05：`non_brand`，非品牌题，用于测试自然发现、自然提及、自然推荐。
- Q06-Q07：`brand_cognition`，品牌认知题，用于测试平台是否知道品牌、主体是否混淆、描述是否准确。
- Q08：`comparison`，品牌/竞品/替代方案对比题，用于测试平台在对比场景中的品牌理解与推荐语义。

## 生成规则

工作台的“根据主体资料生成”优先调用受约束的 OpenAI 兼容模型：模型只负责把主体资料和可选场景资料改写成自然用户问法，固定的 `QUESTION_SLOTS` 负责八题数量、顺序、分类和元数据。模型未配置、不可用或候选未通过质量门禁时，明确回退到确定性的本地生成器；不会调用外部搜索或诊断平台。可选资料包括典型客户/行业场景、客户常见触发问题、主要替代方案或竞品；老项目缺少这些字段时使用通用场景仍可生成。

每题只有一个主意图，最多附带一个必要的决策约束，题目应像用户直接问 AI 的话，例如“我在广州，刚成立的小微企业，想找设备维护服务，应该怎么选？”或“这类服务一般怎么收费？预算主要受哪些因素影响？”。生成结果会附带 `layer`、`subcat`、`intent`、`time_sensitivity`、`trigger_intensity` 标签，用户仍可逐题编辑后保存。模型输出不是企业事实，不能编造资质、案例、客户、价格、效果或承诺；保存和冻结前都会再次执行本地门禁并要求人工确认。

质量门禁在冻结时再次执行：题目必须非空、无占位符、互不重复、长度适合对话框，不能含审计式元指令或明显的多个完整问题；Q01-Q05 不得含主体名称、别名、官网 URL，Q06-Q08 应明确提到主体名称或别名。质量错误会以中文提示返回，不能创建冻结批次。老配置缺少新增标签时仍可冻结，执行器继续原样提交冻结 prompt。

## 非品牌题硬规则

`non_brand` 题不得出现：

- 品牌标准全称
- 任一别名
- 官网域名或官方页面 URL
- 能唯一指向品牌的特殊产品名/口号（除非这是行业通用词）

## 推荐题设计

Q01 应为真实购买意图推荐/选择题，避免写成诊断人员的任务指令。Q02-Q05 覆盖价格/预算、替代方案、风险触发场景、典型客户与实施选择。

## 品牌题设计

Q06 应问“是什么/做什么/服务谁”；Q07 应问“适合谁/什么情况下值得考虑”；Q08 应问“与竞品或替代方案相比如何选择”。不要加入“请注明信息来源”“哪些信息已能验证/无法核实”“请区分已知事实”等审计式文案。

## 验收清单

- [ ] 8 个 ID 唯一，格式 Q01-Q08。
- [ ] Q01-Q05 不含品牌词、别名、网址。
- [ ] Q01-Q05 不重复，覆盖不同购买/认知场景。
- [ ] Q06-Q08 能验证品牌认知、准确性与对比理解。
- [ ] 每个平台重复次数为 1。
- [ ] 冻结配置中的 prompt 与浏览器执行提交内容一致。

`questions.tax-agency.json` 是历史行业参考模板，不是当前生成器的唯一行业逻辑。
